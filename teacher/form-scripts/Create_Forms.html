Create_Forms.gs - copy and paste into Google Apps Script

Generates one self-reflection Google Form per course (Core Pure, AS/A level Pure and Applied).

How to use: 1) Click Copy all. 2) Go to script.google.com - New project. 3) Select all in the editor and paste this in. 4) Save, then run createAllForms. 5) Approve permissions; the links to each Form appear in View - Logs.
If you see "Something went wrong, try again": pick createAllForms from the function dropdown before pressing Run, and make sure you have Saved first. It is often just a temporary Google hiccup — run it again. The script now builds each course separately, so if one fails the others still work (check View - Logs). You can also run a single course, e.g. createAS_Pure.
